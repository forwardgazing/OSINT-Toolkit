# 🔍 Шпаргалка по Google Dorks для OSINT и Threat Intelligence

**Google Dorks** — это специальные операторы поиска, которые позволяют находить скрытую информацию, служебные файлы и следы утечек, невидимые при обычном поиске. В OSINT и Digital Risk Protection (DRP) они используются для проактивного поиска угроз.

---

## 1. Поиск утечек и конфиденциальных данных
*Используется для поиска документов, которые сотрудники случайно выложили в открытый доступ, или баз данных, слитых на публичные ресурсы.*

*   `site:pastebin.com "company_name"` — поиск упоминаний компании на сайтах для обмена текстом (часто там сливают базы).
*   `filetype:pdf site:company.ru "конфиденциально"` — поиск PDF-документов с грифом секретности на официальном сайте.
*   `filetype:xlsx site:company.ru "пароль"` — поиск Excel-таблиц, где могут быть сохранены пароли.
*   `"@company.ru" "password"` — поиск сочетания корпоративной почты и слова «пароль» в открытом доступе.

## 2. Поиск уязвимой инфраструктуры
*Используется для аудита периметра безопасности компании (поиск забытых тестовых серверов, открытых панелей управления).*

*   `inurl:admin intitle:login` — поиск открытых панелей авторизации администратора.
*   `intitle:"index of" "backup"` — поиск открытых директорий с бэкапами (резервными копиями).
*   `site:*.company.ru -www` — поиск поддоменов компании (там часто висят забытые тестовые среды).
*   `inurl:phpinfo.php` — поиск открытых файлов конфигурации PHP (утечка версий ПО и путей).

## 3. Поиск фишинговых ресурсов
*Используется для выявления сайтов-клонов и мошеннических страниц, маскирующихся под бренд компании.*

*   `inurl:login site:*.ru "Сбербанк"` — поиск страниц авторизации на разных сайтах, где упоминается Сбербанк.
*   `intitle:"Вход в систему" "Госуслуги"` — поиск страниц с заголовком «Вход в систему» и упоминанием Госуслуг.

## 4. Поиск сотрудников и корпоративной информации
*Используется для сбора информации об организации (социальная инженерия, проверка контрагентов).*

*   `site:linkedin.com "company_name" "инженер"` — поиск сотрудников компании на LinkedIn по должности.
*   `site:hh.ru "company_name"` — поиск вакансий компании (может раскрыть используемый технологический стек).

---
> **⚠️ Disclaimer:** Данные запросы предназначены исключительно для легального сбора информации (OSINT) в целях защиты бренда и обеспечения информационной безопасности. Использование Dorks против чужих ресурсов без разрешения может нарушать законодательство.
