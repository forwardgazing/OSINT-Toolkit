🕵️ OSINT-Toolkit (Инструменты и методы OSINT)
Набор материалов и скриптов для проведения аналитических расследований, поиска утечек и мониторинга цифровых рисков (Digital Risk Protection).

📌 Что внутри:
Google Dorks Cheat Sheet — шпаргалка по операторам поиска для выявления скрытых данных, открытых документов и следов компрометации.

Whois-Domain-Checker — скрипт на Python для быстрой проверки подозрительных доменов (дата регистрации, регистратор, страна). Помогает выявлять фишинговые ресурсы (созданные недавно на анонимных хостингах).

🎯 Для чего это нужно (Применение):
Поиск фишинговых сайтов-клонов.

Выявление утечек данных и неструктурированной информации.

Проверка контрагентов и индикаторов компрометации (IoC).

Сбор доказательной базы для отчетов.
