# 🕵️ OSINT & Digital Risk Protection Toolkit

Набор практических инструментов для аналитических расследований, мониторинга цифровых рисков и проверки доменов. 

Данный репозиторий создан как демонстрация практических навыков в области **OSINT (Open Source Intelligence)** и **Threat Intelligence**.

## 🎯 Решаемые задачи
*   **Поиск фишинговых ресурсов:** Выявление молодых доменов (возраст менее 90 дней), которые часто используются для атак.
*   **Анализ инфраструктуры:** Определение IP-адреса, провайдера (ISP) и физической геолокации сервера (GeoIP).
*   **Обнаружение маскировки:** Выявление использования CDN (Cloudflare, Akamai и др.), за которыми злоумышленники скрывают реальный хостинг.
*   **Сбор доказательной базы:** Гибридный парсинг данных из реестров WHOIS и RDAP.

## 📂 Структура репозитория
*   **`google_dorks.md`** — Шпаргалка по операторам поиска Google для поиска утечек и открытых админок.
*   **`whois_checker.py`** — Скрипт на Python для комплексного анализа доменов.

## 🛠️ Технологии и инструменты
*   **Python 3**
*   **WHOIS (Socket)** — прямое подключение к серверам популярных зон (RU, KZ, BY, UA, EU и др.).
*   **RDAP (whoisit)** — современный протокол для международных зон (.com, .org).
*   **GeoIP (ip-api.com)** — бесплатный API для геолокации.
*   **Google Dorks**
